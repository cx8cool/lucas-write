# seed 模式 · 选题参谋

先读 `WS/profile/identity.md`（受众 + 选题标准 + 不做的题）、`data-sources.md`（必搜清单）、`keyword-mapping.md`（搜索词）。这三个文件还是 TODO 时照常跑，但搜索词按他的领域自己拟，并提醒他第 5 轮能让选题更准。

## Step 1 输入
他给方向就在方向内深挖；没方向就搜本周他领域的全部高相关话题。

## Step 2 联网搜索
用 data-sources.md 的"必搜"清单 + keyword-mapping 里对应话题的英文术语，优先 7 天内。
Codex 默认带联网搜索。如果搜索工具不可用：让他用 `codex --search` 重新启动，或者直接把这周看到的新闻/数据贴给你，照样往下走。

提取三类素材：新数据点（精确数字）、新事件（政策/机构动作）、新矛盾（多数人信 X，数据说 Y）。

## Step 3 筛选
按 identity.md 的 5 条选题标准 + 他的补充标准内部打分，剔除"不做的题"，留前 5。查 `knowledge-compact.md`，候选题和他一贯判断冲突的要标出来（可能正是反转题材，也可能该避开，让他定）。

## Step 4 输出（每题）
```
## 选题 N：[核心关键词]
**核心角度：** [一句话判断，结论前置]
**标题方向：** 3 个（按 title-formulas.md 的公式各出一个）
**为什么现在做：** [时机 + 数据或事件]
**关键数据点：** 2-3 个精确数字，注明来源
**与他过去观点的关系：** 延续 / 反转 / 新领域
**预估 rubric：** XX 分（最强的 1-2 项）
```

## Step 5 结尾
"哪个方向对？确认后直接写稿，或者再往这个方向挖。"
把 5 个选题存到 `WS/drafts/seed_YYYY-MM-DD.md`。
