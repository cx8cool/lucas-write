# 第 0 轮：让他现有的 AI 导出记忆

把下面整段原样贴给他，让他贴进 ChatGPT / Claude / 任何他长期用的 AI。回答存成 `~/lucas-write/imports/ai-memory-export.md`。

---

```
我要把你对我的了解迁移到另一个写作工具里。请把你记忆里关于我的所有信息，按下面的结构完整输出成 Markdown。不要省略、不要概括、不要客气，不确定的条目后面标"（不确定）"，完全没有的栏目写"无记录"。

## 1. 我是谁
职业、背景、所在城市、做什么内容、在哪个平台、更新频率、做内容的目标

## 2. 我的受众
他们是谁、关心什么、怕什么、我通常怎么称呼他们

## 3. 我的写作和说话风格
开场习惯、口头禅、常用句式、段落长短、节奏、结尾习惯、常用的比喻或类比、我喜欢和讨厌的表达方式

## 4. 我反复讲的观点
我一贯的判断（"我一直认为……"），每条一句话

## 5. 我自己的案例
我提到过的项目、客户故事、具体数字

## 6. 我纠正过你的地方
我说过"不要这样写""改成那样"的所有记录，尽量引用我的原话

## 7. 我做过的内容
你记得的我写过或做过的题目、标题，尽量列全

## 8. 我不碰的
我说过不写、不用、不提的词、话题、写法
```

---

补充提示给他：ChatGPT 还可以在 设置 → 个性化 → 管理记忆 里把记忆条目复制出来，一起贴到文件末尾。
