# 脚本结构模板（script-templates）

> 第 3 轮由 AI 从样本反推后他修改。字数按 identity.md 里的规格算（默认 200 字 ≈ 1 分钟）。

## 长视频模板
（默认版，训练后替换）
```
【开场钩子】（100-150 字）反直觉问题 / 真实冲突案例 / 回顾上期制造反转
【固定开场白】（如有）
【核心结论前置】（50-100 字）
【主体拆解】三个维度，每个 300-500 字
  维度 1 现象/数据层：发生了什么
  维度 2 逻辑/原因层：为什么
  维度 3 影响/机会层：对观众意味着什么
【中段 CTA】视频 1/2 处，一个论点收尾后
【实战案例】（150-300 字）无则标 [Lucas 补充]
【观众怎么判断】（100-200 字）落地动作，可留下期悬念
【收尾 + 行动呼吁】固定结束语
```

## 结构使用原则
1. 三点结构是默认，除非话题本身决定两点或四点
2. 每个维度必须有数据，纯观点段不超过 3 行
3. 案例放在维度 3 之后或中间
4. 中段 CTA 不打断论证
5. 结论开头说一次，结尾不复述，可升华
