# 设计说明（给维护者）

## 结构
- `SKILL.md`：路由。每次调用先跑 `lw.py status --json`，再按意图读 `references/mode-*.md`。
- `references/`：7 个模式 + 提炼方法 + 导出提示词。seed/write/title/qa 的执行步骤沿用西城李老斯 weili-skills，只是所有"人"的内容改从 profile 读。
- `assets/profile-template/`：8 个 profile 模板，带默认值和 TODO。train 逐轮替换 TODO。
- `scripts/lw.py`：工作区管理（init / status / round / snapshot / rollback / wrote / metric）。
- `scripts/transcribe.py`：视频 → samples/raw。官方字幕 → 自动字幕 → FunASR；字幕密度 < 2 字/秒视为部分字幕回退 FunASR。

## 数据
全部在 `~/lucas-write/`（可用环境变量 `LUCAS_WRITE_HOME` 改）。`state.json` 记轮次、ready/graduated、指标、待回收修改。profile 改动前必须 snapshot。

## 为什么是一个 skill 不是五个
Codex 的 skill 列表只占 2% 上下文；一个 skill 多模式占一行。Codex 没有 plugin 根目录变量，SKILL.md 用"SKILL_DIR = 本文件所在目录"约定。

## 测试
本机：`LUCAS_WRITE_HOME=/tmp/x python3 scripts/lw.py init` 后跑各子命令；`transcribe.py --url <单视频> ` 验证字幕和 FunASR 两条路。Codex 冒烟：把仓库软链到 `~/.agents/skills/lucas-write`，`codex exec '$lucas-write 状态'`。
